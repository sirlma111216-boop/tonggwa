## 선별 결과

고1 과학/통합과학 2025·2026년 3·6·9월 145문항을 문항별로 분류했다. 3월 45문항과 이후 회차의 12문항, 총 57문항을 중학교 복습용으로 편성했다.

| 회차 | 포함 문항 | 수 |
|---|---|---:|
| 2025년 3월 | 1~20 | 20 |
| 2025년 6월 | 1, 3, 22, 25 | 4 |
| 2025년 9월 | 2, 10, 15 | 3 |
| 2026년 3월 | 1~25 | 25 |
| 2026년 6월 | 3, 17, 19, 21 | 4 |
| 2026년 9월 | 14 | 1 |

분류는 공식 기관의 판정이 아닌 편집 판단이다. 모든 선택지를 중학교 개념과 문제의 제시 자료로 판단할 수 있는지를 기준으로 한다. 기본량·유도량의 형식적 구분, 전자 껍질·족·주기, 화학 결합, 핵융합, 반도체, 전사·번역, 운동량·충격량 등 고등 개념이 요구되면 제외했다. 중학교와 고등학교가 겹치는 경계 문항도 근거를 남겼다. 예를 들어 2025년 9월 10번은 수용액의 이온으로 해결할 수 있어 포함하지만, 2025년 6월 14번은 이온 결합 분류가 보기에서 요구되어 제외했다. 생물다양성의 세 수준 구분 문항은 보수적으로 제외했다. 따라서 57문항은 이 기준에 따른 선별 결과이며 중학교 전체 교육과정의 완전한 커버리지를 뜻하지 않는다.

원본 데이터는 `content/march/editorial.json`, 전체 판정표는 `content/march/classification.csv`다. JSON에는 6회 정답표, 145문항 주제·판정 근거, 선택 57문항의 페이지·복습 연결, 자체 집필한 38개 개념 카드가 있다. 앱 안의 검토 목록에서도 모든 포함·제외 문항을 확인할 수 있다.

## 학습과 기록

- 새 문제는 영역을 순환하여 최대 5개 선정하며 세트 내 중복을 막는다. 회차별 세트는 번호순으로 최대 5개씩 나눈다.
- 기본 설정에서 2026년 3월 25문항을 새 문제·복습·회차 연습에서 제외해 점검용으로 남긴다. 사용자가 설정을 해제하면 연습에 포함한다.
- 연습: 선택 답과 확신 정도 제출 → 정오답 → 짧은 개념·풀이 단서·혼동점 → 자체 O/X 확인 → 다음 문항.
- 점검: 25문항 모두 응답한 뒤 일괄 채점한다. 제출 전 정답 자료를 요청하지 않는다. 제한 시간이나 공식 환산 점수는 적용하지 않는다.
- 첫 풀이 기록과 재풀이 이력을 각각 보존한다. 오답, 불확실한 정답, 개념 확인 오답은 복습 대상이다. 이미 본 시험 문제를 새 문제라고 표시하지 않는다.
- 진행 중 세트와 답변은 계정별 `tonggwa:march:v1:<uid>` localStorage에 저장한다. 저장 오류를 화면에 알린다. 기존 단원·평가원 학습 기록과 별도이며 서버 동기화는 없다.

## 빌드와 검증

`npm run content`가 기존 콘텐츠에 이어 `scripts/build-march-bank.mjs`를 실행한다. 공개 생성물은 `public/march/bank.json`, `public/march/answers.json`이며 git에서 제외한다. 문제 목록에 정답·개념 설명은 넣지 않는다. 정적 앱이므로 이를 보안상 시험 감독 기능으로 해석하지 않는다.

`npm run test:march`는 전체 분류·키·페이지·고유 ID, 영역별 새 문제 배정, 점검 문제 유보, 재채점 중복 방지, 첫 응답 보존, 기록 복원과 오류를 확인한다. `node scripts/check-march-ui.mjs`는 실행 중인 개발 서버에서 데스크톱·모바일, 제출 전 해설 숨김, 연습 5문항, 새로고침 복원, 점검 25문항 일괄 제출을 확인하고 `tmp/march-exams/ui/`에 화면을 저장한다.
