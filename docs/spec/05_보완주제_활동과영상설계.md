# 감염병 검사·스마트 온실 학습 설계 메모

작성일: 2026-10-17. 대응 원고: `06_과학과미래사회.md`. 아래 내용은 앱 개발 프롬프트에 반영할 설계이며, 앱이나 영상이 제작되었다는 뜻은 아니다. 본문에 없는 원리로 평가하지 않고, 실패한 판단을 해당 설명의 정확한 위치로 연결한다. 기존 교재의 문항 ID와 정답은 유지한다.

## 1. 감염병 검사 — 표적·도구·신호를 구별하는 학습

성취기준: 10통과2-03-01. 근거 본문: ‘항원 검사: 결합한 뒤 무엇이 모여서 보일까요?’, ‘핵산 검사: 필요한 구간을 선택하고 반복해 양을 늘려요’. 애셋: SCI-AUTH-01, SCI-AUTH-02.

### 인터랙션 A: 검사 그림의 역할 분류

처음에는 항원·항체·표지를 동시에 움직이지 않는다. 정지한 원리를 먼저 읽게 하고, 이후 단계별 진행을 허용한다. 학생은 그림의 주황색 항원, 청록색 준비 항체, 붉은 표지를 각각 ‘찾는 물질’, ‘선택적으로 결합하는 도구’, ‘보이게 하는 신호 물질’에 연결한다. 드래그 외에 선택 후 연결 버튼과 키보드 조작을 지원한다. 색만으로 정답을 알려 주지 않고 이름·모양·대체 텍스트를 병기한다.

오답 피드백은 역할을 좁혀 준다. 항체를 표적으로 고르면 “이 모형에서는 항체를 장치에 미리 준비했어요. 검체에서 찾으려는 X는 무엇이었나요?”를 보여 준다. 표지를 병원체로 고르면 “색을 내는 표지는 검출을 돕는 물질이에요. 항원과 같은 역할인가요?”를 보여 준다. 정답만 드러낸 뒤 통과시키지 말고 해당 구별을 다른 기호 X·Y로 한 번 더 확인한다.

다음에는 ‘검사 영역 신호 없음’만 먼저 보이고 판단을 보류하게 한다. 작동 확인 정보가 추가되면 유효성 판단을 먼저 선택하게 한다. 이는 실제 제품의 시간·색 판정 교육이 아니라 교재의 가상 정보 해석 활동이어야 한다. 실제 환자 자료나 개인 증상을 입력받지 않는다.

### 인터랙션 B: 증폭 단계와 수량 모형

카드 순서: RNA 정보를 이용한 DNA 준비(해당할 때만) → DNA 가닥 분리 → 프라이머가 구간 선택에 관여 → 새 가닥 합성 → 반복. RNA 준비는 PCR의 모든 경우에 필수인 것으로 채점하지 않는다. ‘단백질 증폭’, ‘병원체 전체 배양’ 카드는 오개념 비교용으로 제시한다.

수량 모형은 초기 상대량과 반복 횟수를 바꾸되 ‘매회 정확히 2배를 가정’이라는 조건을 항상 고정 표시한다. 3→6→12→24를 학생이 한 단계씩 완성하고, +3을 반복하면 “다음 양은 처음 양이 아니라 직전 양의 두 배예요.”로 안내한다. 화면의 수량을 실제 임상 바이러스 개수나 감염력으로 번역하지 않는다. 새 반복을 보여 주기 전에 예상 값을 입력하게 한다.

### 영상 제안

- 항원 검사 3~4분: 0:00 표적·도구·신호 분류, 0:45 선택적 결합, 1:30 고정된 포획 항체에 모임, 2:15 대조와 신호 해석, 3:00 X·Y 모형 확인. 비유 대신 분자의 기능과 순서를 말한다. SCI-AUTH-01을 확대·강조하고 마지막에는 전체 그림을 다시 보여 준다.
- 핵산 증폭 4~5분: DNA와 단백질 구분, 가닥 분리/프라이머/합성, RNA 준비 경로, 3→6→12→24 계산, ‘증폭≠배양’ 확인. 반복 단계 사이에 정지하여 학생이 다음 상태를 예측할 시간을 둔다. 온도·효소 명칭의 과도한 암기는 요구하지 않는다.

영상에는 검수된 자막·전문·정지 화면 대체 자료를 제공한다. 영상 없이도 본문만으로 같은 원리와 평가 근거를 얻을 수 있어야 한다.

### 형성평가 초안

| 임시 설계 ID | 질문 | 정답 근거·피드백 |
|---|---|---|
| F-INF-01 | 준비한 항체 Y로 단백질 X를 찾았다. 표적과 도구는? | 표적 X, 도구 Y. ‘항체를 이용함’과 ‘항체를 검출함’ 구별 |
| F-INF-02 | 출발 물질이 RNA인 이 방식에서 PCR이 직접 늘리는 물질은? | 준비한 DNA. RNA→DNA 준비와 DNA 증폭의 단계 구별 |
| F-INF-03 | 초기 상대량 5, 매회 두 배 가정, 3회 뒤의 양은? | 40. 5→10→20→40. 실제 임상 단위로 환산하지 않음 |
| F-INF-04 | 표적 DNA의 양이 늘었으므로 살아 있는 병원체도 같은 배수로 늘었는가? | 해당 결론은 근거 없음. 특정 핵산 증폭과 전체 병원체 배양 구별 |

이 ID는 설계용이며 기존 T2 문항 집합에 자동 추가하지 않는다. 첫 응답 정오·시도 횟수·오개념 태그·근거를 읽었는지·새 자료에서의 재확인을 저장한다. 단순 반복 클릭 횟수를 이해도 점수로 삼지 않는다.

## 2. 스마트 온실 — 세 경로와 순차 제어를 읽는 학습

성취기준: 10통과2-03-03. 근거 본문: ‘연결 그림에서 정보·물·에너지의 경로를 구별해요’, ‘완결 예: 측정값 22가 펌프 작동으로 이어지는 전 과정’, ‘값이 틀린 것인지, 전달이 늦은 것인지, 물이 안 온 것인지’. 애셋: SCI-AUTH-03.

### 인터랙션 A: 정보·물·전기 경로 켜기

그림 전체를 먼저 보여 주고 세 경로를 개별 강조할 수 있게 한다. 정보 경로를 선택하면 측정값·측정 시각·전달·판단·명령을 순서대로 강조한다. 물 경로에서는 탱크·펌프·배관·토양만 강조한다. 전기 경로에서는 전원이 펌프의 운동을 가능하게 함을 보여 주고 다른 전원선은 가독성을 위해 생략되었다는 설명을 유지한다.

학생이 ‘물’을 통신선에 연결하면 “이 선을 따라 이동하는 것은 측정한 수치예요. 실제 물이 지나가는 관을 찾아보세요.”를 보여 준다. 센서가 직접 펌프를 돌린다고 고르면 측정·판단·실행의 세 칸을 다시 채우게 한다. 과도한 애니메이션 대신 단계 강조와 학생의 예측을 중심에 둔다.

### 인터랙션 B: 실행 기록을 읽는 제어 모형

교재와 동일한 규칙을 사용한다. 무단위 수분 지수 0~100, 30 미만이면 10초 급수, 급수 후 기다렸다 새로 측정, 누적 최대20초, 정상·최신 측정만 판단에 사용. 기준값·가상 지수임·실제 농업 권장값이 아님을 항상 표시한다. ‘현재 측정’, ‘전달 완료’, ‘판단’, ‘펌프 실행’, ‘기다림’, ‘재측정’, ‘제한 도달’ 상태를 구분한다. 기다림과 펌프 실행 시간을 합쳐 누적 급수 시간으로 계산하지 않는다.

기본 기록은 22→27→32이다. 학생은 각 단계에서 급수/대기/점검 중 다음 행동을 고른다. 이후 22→27→25로 바꿔 누적20초 제한이 30 미만 조건보다 우선함을 확인한다. 또 30을 넣어 경계값에서 추가 급수가 없음을 확인한다. 숫자가 없는 기록을 0으로 처리하거나 오래된 값을 새 측정으로 취급하면 오답으로 판정한다.

가상 수치와 상태 전이는 결정적인 규칙으로 계산한다. 생성형 API가 제어 결과나 채점 정답을 임의로 바꾸지 못하게 한다. 생성형 설명을 붙이는 경우에도 수록된 규칙·근거 문장·검수된 오답 사유를 입력 근거로 제한한다.

### 인터랙션 C: 고장 원인을 조건부로 좁히기

‘낮은 값이 계속 뜸’, ‘값은 전달되지만 명령 없음’, ‘명령은 있으나 물 없음’, ‘원격 화면 갱신 중지’ 네 기록 중 하나를 제시한다. 학생은 센서·통신·제어·전원/펌프/배관의 확인 자료를 선택한다. 하나의 기록으로 고장 위치가 확정되지 않는 경우 ‘추가 자료 필요’를 정답으로 인정한다. “AI를 더 똑똑하게 만들기” 같은 원인 불명의 개선안을 정답으로 처리하지 않는다.

### 영상 제안

- 연결 원리 3~4분: 측정한 수치와 실제 물 구별 → 세 색 경로 → 명령과 실제 급수 구별 → 다시 측정. 외형 이름을 나열하지 말고 입력과 출력을 한 단계씩 연결한다.
- 제어 판단 4~5분: 지수22 판단 → 10초 실행과 정지 → 기다림과 새 지수27 → 두 번째 실행 → 지수32에서 정지. 이어25 잔류·누적20초와 정확히30의 경계값을 비교한다. 영상 중간에 다음 행동을 묻는다.

### 형성평가 초안

| 임시 설계 ID | 질문 | 정답 근거·피드백 |
|---|---|---|
| F-FARM-01 | 전송선으로 옮겨지는 것은 물인가, 측정 정보인가? | 측정 정보. 물은 탱크·펌프·배관을 지남 |
| F-FARM-02 | 정상 새 지수가 정확히30이면 추가 급수하는가? | 하지 않음. 조건은 30 미만이지 이하가 아님 |
| F-FARM-03 | 누적20초 뒤 지수25이면 어떤 행동인가? | 추가 급수 없이 점검. 안전 제한과 기준 미달을 함께 적용 |
| F-FARM-04 | 명령 기록이 있으면 물이 도착했다는 뜻인가? | 아니며 전원·장치·배관·잔량 확인 필요 |
| F-FARM-05 | 센서와 고정 기준으로 자동 급수하면 반드시 기계 학습인가? | 제시된 정보로 단정 불가. 자료로 모형을 학습한 근거가 필요 |

숙달은 역할 분류, 순차 규칙, 경계값, 새 측정의 필요, 제한 조건, 원인별 확인을 각각 기록한다. 한 계산을 맞혔다는 이유로 전체 단원을 숙달 처리하지 않는다. 오답은 해당 본문과 도해 위치로 연결하고 다른 수치·상태의 재확인에서 전이를 확인한다.

## 공통 유지·개선 원칙

본문 버전, 도해 버전, 형성평가 버전, 출처 확인일을 함께 기록한다. 새로운 공식 문항의 요구가 추가되면 필요한 근거가 본문에 있는지 먼저 확인하고 설명→예시→평가의 순서를 유지한다. 문항만 늘려 근거 없는 평가를 만들지 않는다. 최신 제품·진단 규칙·재배 권장값으로 확장할 때는 이 모형을 그대로 실제 지침으로 사용하지 말고 해당 용도의 공식 자료와 전문가 검토를 별도로 거친다.
