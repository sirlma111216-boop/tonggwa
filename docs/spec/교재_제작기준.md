# 통합과학 교재 집필과 문항 도판 제작 기준

사용자 요구 반영: 2026-10-17. 이 기준은 교재와 이후 웹앱에 적용한다.

**최신 편집 방식:** 지금은 도판을 전부 생성하지 않는다. 검토용 교재에 교과서·하이탑 원본 그림을 넣고, 바로 옆에 원본 출처·바꿀 내용·재제작용 전체 프롬프트를 붙인다. 사용자가 교재를 검토하며 필요한 그림을 선택할 때 Imagegen으로 제작한다. 이미 생성한 도판은 버전 기록과 함께 보관한다. 이 지시는 아래의 최종 도판 재제작 원칙에 앞서 적용하는 검토 단계의 방식이다.

## 교재의 위상과 설명의 충분함

**교재는 웹앱의 바이블이자 기준 원본이다.** 앱에는 개념을 이해하는 데 필요한 상세 설명을 보존하며, 필요한 부분은 더 풀어 쓴다. 교재와 앱의 본문을 임의로 요약하거나 누락하지 않는다. 기존 검토본의 분량이나 화면 크기를 설명량의 상한으로 삼지 않는다.

새롭거나 어려운 개념은 용어의 뜻, 필요한 선개념, 왜 그런 관계가 성립하는지, 조건과 한계, 중간 추론, 구체적 예와 비예, 수치·단위, 그림·표·그래프를 읽는 과정, 오개념과 문제 적용까지 해당 개념에 필요한 내용을 충분히 설명한다. 읽기 편하도록 소제목과 장면을 나눌 수 있으나, 필수 설명을 삭제하거나 선택 도움말 뒤에 숨기지 않는다. 요약은 상세 학습 뒤의 복습 보조로만 사용한다. 학생이 이미 아는 부분을 건너뛰는 것은 개인의 경로 선택이며 상세 본문의 축약을 뜻하지 않는다.

## 모든 문항의 학습 근거 확인

**문항의 요구에는 교재의 학습 근거가 있어야 한다.** 문항과 각 선지의 판단에 필요한 개념·조건·자료 해석·추론 방법을 교재의 구체적인 설명 위치와 버전에 연결한다. 성취기준 코드나 단원 제목만 같다고 설명 근거가 충분하다고 판정하지 않는다.

처음 보는 자료나 개념을 결합하는 문제도 배운 원리와 문제에 제공한 정보로 답을 도출할 수 있어야 한다. 풀이 결과나 같은 문제를 미리 가르쳐야 한다는 뜻은 아니다. 새 용어·규칙·공식이 풀이에 필수인데 본문에서 배우지 않았고 문제에도 제공되지 않았다면 근거 누락으로 처리한다. 해설에 처음 등장하는 필수 개념이 있는지도 점검한다.

편집자 대조표에는 문항·선지, 필요한 지식과 사고, 교재의 설명 위치·버전, 문제에서 새로 제공하는 정보, 이를 연결하는 풀이 단계, 학생의 실제 학습·건너뛰기 상태, 누락과 보완 상태를 기록한다. 콘텐츠의 설명 유무와 학생이 그 설명을 학습했는지는 구별한다. 근거가 빠진 문항은 준비된 평가에 넣지 않고 교재를 보완한 뒤 다시 검토한다. 평가원 원문에 필요한 배경이 부족하면 원문은 보존한 채 사전 학습을 보완한다.

설명을 줄이거나 옮기거나 고칠 때는 연결된 문항·모든 선지의 해설·영상·힌트·전략·복습을 함께 확인한다. 교육과정 밖 배경을 필수 과정에 무작정 추가하지 않고, 필수·확장 범위를 대조하여 처리한다. 교재 설명과 평가 요구의 연결 검토는 문항 수와 일곱 단계의 존재 확인만으로 완료되지 않는다.

## 범위와 완성 기준

교재는 2022 개정 통합과학1·2의 개념에서 수능 실전으로 이어진다. 단위 학교의 기출 분석은 교재에 포함하지 않으며, 이후 웹앱의 학교별 기능에서 다룬다. 기존 자료 분석 기록과 학생용 교재 완성은 구분한다.

각 소단원은 **선개념 → 개념 → 개념평가 → 심화개념 → 심화평가 → 수능대비 전략 → 수능대비평가**를 모두 포함한다. 필요한 개념을 가르치기 전에 평가에서 먼저 요구하지 않는다. 선수 학습은 중학교 학년을 고정하지 않고 현재 개념에 필요한 결손을 보충한다.

선개념에는 진단과 보충 설명, 개념에는 원리·예·비예·조건·오개념, 심화에는 교육과정 안에서의 자료 해석과 여러 개념의 연결을 넣는다. 수능 전략은 왜 묻는지, 처음 확인할 것, 풀이 순서, 적용 조건과 반례를 함께 설명한다. 어려운 내용은 분량에 맞추려고 추론 중간 단계를 생략하지 않는다.

평가는 정답뿐 아니라 단계별 풀이, 모든 선지의 판정 근거, 오답 원인 후보, 돌아갈 설명과 재도전 조건을 포함한다. 원문·자작·변형을 구분하고, 실제 학생 통계가 없는 난도는 설계상의 목표 난도라고 표시한다. 평가원 예시를 실제 2028 수능 기출로 부르지 않는다.

## 구어체와 문어체

이해를 돕는 본문 설명, 학생에게 건네는 확인 질문, 풀이 안내와 힌트는 자연스러운 해요체를 사용한다. 예: “먼저 무엇이 같고 무엇이 달라졌는지 찾아볼까요? 질량과 충돌 전후 속도가 같다면 운동량 변화도 같아요.”

정의, 공식, 성립 조건, 과학적 결론, 표의 항목, 평가 문항과 선택지는 문어체로 명료하게 쓴다. 예: “평균 힘의 크기는 같은 운동량 변화에서 충돌 시간에 반비례한다.” 친근한 설명이 조건을 흐리거나 근거 없는 의인화로 바뀌지 않게 한다.

새 용어는 처음 나올 때 뜻·이전 개념과의 관계·구체적 예를 설명한다. 표·그림·수식도 읽는 순서를 가르친다. 길어진 설명에는 작은 중간 확인을 두되, 질문 하나를 틀렸다는 이유만으로 학생의 결손을 확정하지 않는다.

## 문항의 출처에 따른 사용 규칙

| 자료 | 학생용 교재 적용 |
|---|---|
| 교과서·수활북·하이탑 문항 | 원문 그대로 수록하지 않는다. 목표 난도에 맞게 상황·조건·자료·질문·선지·추론 요구를 재구성한다. |
| 해당 자료의 문항 그림 | 현재 검토본에는 원본 그림과 옆의 재제작 메모·전체 프롬프트를 넣는다. 사용자가 선택하면 Imagegen으로 일관되게 재제작한다. |
| 평가원 제공 문항 | 사용자 지시에 따라 원문 문제·수치·그림·선지·배점을 유지한다. 설명·힌트는 원문 바깥에 구분한다. |
| 완전 신규 문항·그림 | 자작 또는 신규 제작이라고 표시한다. 대응하는 원본이 있는 것처럼 출처를 만들어 붙이지 않는다. |
| 교육청 학력평가 | 평가원 문항과 구분한다. 평가원 원문 보존 지시를 교육청 자료 전체에 자동 확대하지 않는다. |

원문 보존은 오탈자까지 임의로 고치지 않는 것을 원칙으로 한다. 공식 정정본이 확인되면 원본·정정본과 적용 내역을 함께 관리한다. 필요 부분 추출은 문제와 그림·보기·선지·배점이 잘리지 않도록 하며, 원문 PDF도 보존한다. 현재 확보한 2028 체제 평가원 통합과학 공식 예시는 2024년 12문항과 2025년 25문항, 총 37문항이다. 다른 교육과정의 과학 선택과목 전체를 이 수록 범위와 혼동하지 않는다.

출판사 원본 그림을 변형 문제에 그대로 대응시키면 조건이 어긋날 수 있다. 이 경우 ‘재제작 참고용 원본’이라고 표시하고, 정확한 풀이 조건은 본문·수치표로 완결한다. 그림만 원본을 임시 사용한다는 지시를 교과서·하이탑의 지문·선지까지 그대로 수록해도 된다는 뜻으로 확대하지 않는다.

문항을 변형하거나 다시 그렸다는 사실만으로 상업 이용 권한이 자동 확보되었다고 표시하지 않는다. 상업 공개의 권리 검토 상태는 편집자 기록에서 별도 관리한다. 이번 로컬 교재 제작과 외부 상업 공개는 구분한다.

## 이미지별 필수 제작 기록

1. 이미지 식별자, 사용 문항과 학습 목표, 목표 난도.
2. 원본의 출판사·책명·권·파일 경로·PDF쪽수·인쇄쪽수·문항번호·그림 위치. 원본이 없으면 ‘신규 제작’.
3. “어떤 원본 그림을 무엇으로 바꾸는지”를 적은 한국어 변경 지시.
4. 유지해야 하는 과학적 관계와 바꾸는 조건·수치·배치·색상·표현.
5. Imagegen에 실제 전달한 전체 프롬프트와 참조 이미지 경로. 새 버전에서는 이전 기록을 덮어쓰지 않음.
6. 생성 방식·일시·선택한 결과 파일·파일 해시·버전·검토 내용.
7. 재수정용 지시와 오류 발견·수정 이력. 프롬프트만으로 동일한 픽셀이 재생성된다고 보장하지 않으므로 채택한 이미지도 보존.

도판의 표준은 흰 배경, 선명한 검정 축·윤곽, 주된 자료의 파랑, 비교 요소의 제한된 보조색이다. 장식보다 변수·관계·단위의 판독을 우선한다. 색만으로 정답 정보를 구별하지 않게 표식·문자·선 모양을 함께 쓴다. 수치형 그림은 눈금·단위·부호·자료표·정답을 교차 확인한다. 필요한 경우 그림이 개략도임을 밝히고 수치표를 함께 제공한다.

## 검토 완료 조건

31개 성취기준과 세부 개념을 대조하고, 일곱 단계의 존재뿐 아니라 실제 학습 내용과 평가의 대응을 확인한다. 계산 문항은 단위·부호·정답 유일성을 검산한다. 선택지마다 참·거짓의 근거가 있어야 한다. 그림은 본문 조건과 일치해야 하며 PDF는 한글·수식·표·도판의 잘림을 확인한다. 출판사 원문 무변형 수록, 평가원 원문 임의 변형, 학교 기출 분석 혼입, 프롬프트 누락을 점검한다.
