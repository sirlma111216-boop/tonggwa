# 원소와 우주 · 별과 생명 영상 제작 지침

기준일: 2026-10-19. 이 문서는 앱에 연결된 30개 개념·보충·전략 카드의 자체 제작 영상 기획서입니다. 현재 영상 파일은 제작하지 않았습니다. 학생 화면에는 해당 개념의 영상 자리와 확인 질문을, 제작자용 펼침에는 장면 지침을 제공합니다.

## 제작의 공통 기준

- 각 클립은 45~90초를 목표로 하되, 복잡한 내용을 속도를 높여 압축하지 않습니다. 필요하면 한 개념 안에서 두 짧은 장면으로 나눕니다.
- 도입은 개념에 맞춰 관찰·비교·사건 연결·오류 고치기·짧은 적용 중에서 고릅니다. 모든 클립에 억지 예측 문제를 붙이지 않습니다.
- 설명 영상은 학습을 대신 완수하는 자료가 아닙니다. 마지막 확인 질문에서 멈추고 앱의 조작·설명 활동으로 돌아옵니다.
- 자막과 내레이션을 함께 제공하고, 자동 재생과 소리는 기본값으로 강제하지 않습니다. 의미를 색에만 담지 말고 이름·기호·모양을 병기합니다.
- 원자·별·시간표의 모형은 실제 크기·간격에 비례하는지 명시합니다. 선의 실제 파장 자료를 쓰지 않았다면 ‘학습용 가상 원소’라고 밝힙니다.
- 외부 자료는 공개 원문 링크로 연결했습니다. 공개 열람 가능 여부와 복제·편집·상업적 재사용 허가는 다릅니다. 외부 사진·영상의 재사용 여부는 개별 크레딧과 이용 조건을 확인하고, 자체 영상에서는 직접 만든 도해를 기본으로 사용합니다.
- 외부 링크는 필수 수업을 대체하지 않는 선택 자료입니다. 영문 자료라는 점과 볼 지점을 화면에 표시합니다.

## 과학 표현의 검수 기준

- 흡수선은 검은 빛이 더해지는 모습이 아니라 관측 방향의 특정 파장 세기가 상대적으로 약해진 모습입니다.
- 원자핵에 전자를 포함시키지 않습니다. 수 분 무렵의 초기 핵 형성과 약 38만 년 무렵의 중성 원자 형성을 구별합니다.
- 질량비를 원자 수 비로 곧바로 바꾸지 않습니다. 각 총질량을 한 개 질량으로 나눕니다.
- 별의 질량과 진화 단계를 함께 표시합니다. 모든 별이 철 중심부까지 진화한다고 설명하지 않습니다.
- 무거운 원소 생성의 경로를 하나로 한정하지 않습니다. 핵반응, 물질 집적·분리, 생명체의 화학 반응을 구별합니다.
- 지각의 산소 함량은 산소 기체의 부피가 아닙니다. 구성비에는 대상과 질량/개수 기준을 붙입니다.
