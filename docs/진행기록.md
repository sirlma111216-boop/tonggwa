## 2026-10-19 · 원소와 우주 / 별과 생명 탐구 수업

- `unit-1-1`의 14개, `unit-1-2`의 16개 비문항 화면에 전용 수업 흐름·49개 용어 정의·31개 집필 활동 연결. 관찰/탐구가 맞는 개념은 활동부터, 비교/설명/적용은 개념 연결부터 시작한다. 모든 본문 설명과 기존 평가 문항은 유지했다.
- 6종 활동: 스펙트럼 기준 원소 전환, 우주 사건 순서 재구성, 질량별 별 진화와 내부 모형, 질량비/실제 양 보기, 증거 분류, 근거 선택. 선택지별 오답 피드백과 교정 기회를 제공한다.
- 두 참고 도판을 자체 과학 SVG로 대체. 흡수선은 연속 바탕의 어두운 선으로, 방출선은 어두운 바탕의 밝은 선으로 표시하며 관측 범위 밖의 선을 표시 영역에 그리지 않는다.
- 구조적 필기장 각 5쪽 PDF와 인쇄 화면. 제목·목표·빈 관계 구조·자기 점검·보완 공간을 인쇄한다. 앱은 작성 확인 이후 모범 필기와 기준을 공개하고 같은지/보완했는지/다시 볼지를 기록한다.
- 30개 영상 제작 지침에 장면·확인 질문·표현 주의점·공개 외부 자료를 넣었다. 실제 자체 영상은 제작 전이며 가짜 재생 버튼을 넣지 않았다. `docs/pilot-video-briefs.md`에서 전체 제작 순서를 볼 수 있다.
- 안정적인 ID로 활동 조작·최초 응답·재시도 저장. XP는 활동당 최대 10점. 필기 자기 점검과 6개의 별도 새 자료 문제 결과를 구별한다. 화면을 넘긴 것은 화면 진도이며 숙달이 아니다.
- 시작 화면 두 단원 바로가기, 단원 지도 필기장 다운로드, 이해 확인 기록, 새 자료 도전 연결. 입력 중 Enter로 화면이 넘어가는 문제 및 단원 변경 시 이전 단계 상태가 남는 문제를 함께 방지했다.
- 검증: 프로덕션 빌드 통과. 콘텐츠 원본/생성물 연결·31개 활동·30개 카드·93개 위젯 렌더 상태의 689개 점검 통과. 전체 개념 화면 렌더, 제출 전 모범 필기/피드백 숨김, 교정 기록과 보상 제한 테스트 통과. PDF 10쪽을 모두 렌더하여 한글·페이지 나눔·필기 공간 확인.
- 검증 범위: 앱의 실제 브라우저 조작·화면 캡처는 브라우저 접근 정책 제한으로 이번 작업에서 수행하지 않았다. 로컬 미리보기는 사용자 검토용으로 제공한다.
- 2026-10-20 후속 요청: 검토한 변경을 GitHub `main`에 커밋·푸시하여 동기화한다. 기존 GitHub Actions의 Cloudflare 자동 배포 경로를 사용한다.

## 2026-10-17 · 3차: 글만 있던 개념 카드를 ‘보고 누르고 해 보는’ 카드로

사용자 피드백: “단조롭고 글만 있는 여섯 장을 집중해서 읽을 수 없다. 누르면 옆에 추가 설명이 열리고, 개념마다 아래에 상호작용 활동이 있어야 한다.”

- **본문 위계**(`src/features/learn/Markdown.tsx`): `**용어:** 정의` → 정의 카드, `**순서:** ① ②` → 번호 단계 목록, `**그림 읽기.**`·`**완결 예제.**` → 소표제 카드, ‘잠깐 확인해요’ → 생각해 보기 상자, 계산식(`8 ÷ 0.2 = 40`) 강조.
- **용어 패널**: 본문의 굵은 용어를 누르면 오른쪽에 정의·이 단원에서 쓰인 문장(해당 화면으로 이동)·더 깊이(심화 언급)·중학교 연결·외부 검색 링크. 용어집은 `scripts/enrich.mjs`가 원고에서 자동 추출. 집필 보강은 `content/interactives/<unitId>.json`의 `glossaryExtra`, `links`.
- **활동 위젯 11종**(`src/features/learn/widgets.tsx`): 빈칸(cloze)·순서(order)·내 말로 한 줄(reflect)·분류 상자(sorter)·규모 사다리(ladder)·단위 변환기(converter)·비 구하기(ratio)·반향 거리(echo)·분해능(resolve)·O/X(truefalse)·중화 이온 모형(ions). 결과는 `activities`에 저장.
- **집필한 활동**: 1단원(unit-0-1) 11개, 중화 단원(unit-3-4) 7개 = 19개. 나머지 카드는 자동 생성(정의 빈칸 → 수치 빈칸 → 문장 순서 → 내 말로 한 줄) 375개. 글만 있는 카드 0개(보충 설명 카드 10개 제외).
- **도판 43개 삽입**: 원고의 `<!-- FIGURE:REF-xx -->` 자리에 출판사 원본 참고 도판을 넣고 그림 바로 아래에 ‘교과서/하이탑 원본 이미지 · 재제작 필요 (REF-xx)’ 캡션. 등록표 `content/source/index/figures.json`.
- 헤드리스 스크린샷(`scripts/screenshots-learn.mjs`)으로 13장면 확인.

## 2026-10-17 · 2차: 코스웨어식 스텝 플레이어로 학습 화면 재설계

사용자 피드백: “긴 본문을 한 화면에 쌓는 문서 뷰어가 아니라, 시판 AI 코스웨어처럼 개념 하나·문제 하나씩 페이지가 넘어가야 한다.” 시판 코스웨어(클래스팅 AI, 똑똑수학탐험대, Khan Academy, Brilliant, Duolingo 계열)의 공통 구조를 조사해 적용:

- 한 화면 = 한 개념(소제목) 또는 한 문항. 변환 스크립트 `toSteps`가 단계를 696개 화면으로 분할(내용 삭제 없음).
- 상단 진행 막대 + 단계 표시, 하단 고정 주 행동 버튼(확인/다음), 학습 중 사이드 패널 숨김(‘도움 · 노트’로 열기).
- 문항: 선택 → 확인 → 즉시 채점·해설(초록/빨강 피드백) → 다음. 서술형은 자기 점검 전까지 다음 버튼 잠금.
- 단계 요약 화면, 단원 지도(`/learn/:unitId`)에 7단계 경로와 상태.
- 로컬 브라우저(1440×900 에뮬레이션)에서 개념 카드, 선택형 2문항 채점, 서술형 점검 잠금/해제, 단계 요약을 실제로 확인. 스크린샷은 창이 숨겨져 여전히 불가.
