# 통합과학 학습실 (tonggwa)

고등학교 1학년 통합과학 학생용 학습 웹앱 V1. 교재 검토본 0.3(31개 성취기준·32개 학습 묶음·291문항 + 평가원 공식 예시 37문항)을 **선개념 → 개념 → 개념평가 → 심화개념 → 심화평가 → 수능대비 전략 → 수능대비평가**의 일곱 단계로 학습한다.

- 프론트: React 19 + TypeScript + Vite 8
- 배포: GitHub `main` 푸시 → GitHub Actions → Cloudflare Workers Static Assets (`wrangler deploy`)
- 회원·학습 기록: 지금은 로컬(검토용 계정 + 이 기기 저장). Firebase Auth/Firestore 어댑터 자리를 만들어 두었다.
- 생성형 AI: Gemini는 Worker 경로 `/api/ai/review`로만 호출한다(키는 Worker secret). 아직 호출 구현 전이며 화면에는 ‘검토 연결 전’으로 표시된다.

## 실행

```bash
npm install
npm run dev        # 교재 JSON 생성(predev) 후 Vite 개발 서버
npm run build      # 콘텐츠 생성 → 타입 검사 → Vite 빌드 (dist/)
npm run test:pilot # 두 탐구 단원의 집필·렌더링·기록 검증 (Node 24 이상)
npm run test:concept # 빛과 초기 우주 12장면의 조작·피드백·복원·표기 검증
npm run deploy     # build 후 wrangler deploy (로컬에서 Cloudflare 로그인 필요)
```

검토용 로그인 계정은 `src/services/auth/accounts.json`에 이메일과 비밀번호 SHA-256 해시로 들어 있다. 정적 사이트이므로 이 로그인은 접근 통제가 아니라 검토용 문이다. 실서비스 인증은 Firebase로 교체한다.

## 빛으로 읽는 원소와 초기 우주 · 개념 탐구실 (2026-10-20)

`/learn/unit-1-1/concept?s=0`의 개념 단계만 12장면으로 재집필했다. 집필 원본은 `content/lessons/unit-1-1-concept.json`이며 콘텐츠 빌드에서 검증한 뒤 Unit JSON에 포함한다. 원래 교재 원고는 보존한다. 새 수업은 원문 문단을 통째로 덧붙이지 않고 필수 개념을 조작·관찰·판단·교정·정리로 가르친다.

빛 펼치기 → 파장 조절 → 세 스펙트럼 → 눈금 맞추기 → 원소 대조 → 결론의 범위 → 원자 조립 → 냉각과 결합 → 우주 시간표 → 질량비/개수비 → 원소의 기원 → 새 자료 적용. 필기장 5쪽과 기존 영상 제작 지침을 연결한다. 새 안정 ID로 기록해 옛 읽기 완료를 새 탐구 해결로 간주하지 않는다.

개발 서버는 `http://127.0.0.1:5173`에 고정한다. 포트 사용 중이면 다른 번호로 넘어가지 않고 실패하므로 해당 프로젝트의 기존 서버를 확인한 뒤 다시 실행한다. 시작 메시지뿐 아니라 수업 URL의 실제 렌더까지 확인한다.

로컬과 운영은 별개다. 2026-10-20 확인 당시 최신 GitHub 커밋 `b31b6d6`의 빌드는 성공했으나 Actions secret `CLOUDFLARE_API_TOKEN`이 없어 배포가 실패했고, 운영에는 예전 7화면 JSON이 남아 있었다. 운영 반영은 Actions 성공과 운영 URL 콘텐츠 확인까지 마쳐야 완료로 기록한다.

## 원소와 우주 · 별과 생명 탐구 수업 (2026-10-19)

시작 화면의 두 탐구 카드 또는 `/learn/unit-1-1`, `/learn/unit-1-2`에서 엽니다. 기존 일곱 단계와 평가 문항은 유지하면서 30개 비문항 화면에 31개의 집필 활동을 연결했습니다. 스펙트럼 비교, 사건 순서, 별 내부 모형, 구성비 전환, 증거 분류, 근거 선택을 개념에 맞게 사용합니다.

- 필기장: `/workbook/unit-1-1`, `/workbook/unit-1-2`. 각 5쪽의 A4 PDF는 `public/workbooks/`에 있으며 제목·목표가 인쇄된 새 빈 양식입니다. 앱에서 ‘필기했어요’ 이후 모범 필기와 비교합니다.
- PDF 재생성: Python에 `reportlab`, `pypdf` 설치 후 `python scripts/build-workbooks.py`. 설치된 Pretendard 글꼴을 사용합니다. 모범 필기와 평가 기준은 PDF에 넣지 않습니다.
- 영상: `content/interactives/<unitId>.json`의 `lessons[].video`에 30개 제작 지침이 있습니다. 실제 영상 검수 후 `src`에 자체 영상 URL을 넣으면 재생기가 나타납니다. 전체 기획서는 [영상 제작 지침](docs/pilot-video-briefs.md)에 있습니다.
- 기록: 안정적인 활동 ID로 조작 상태·최초 정오답·재시도·필기 자기 점검·새 자료 문제를 저장합니다. 도전 5 XP, 해결 추가 5 XP이며 활동당 10 XP를 넘지 않습니다. 화면 완료·XP·필기 확인은 숙달 판정이 아닙니다.
- 검증: `npm run test:pilot`은 두 단원의 연결 누락, 정답 키, 과학 모형의 데이터 조건, 제출 전 해설 숨김, 상태 복원, 보상 중복을 확인합니다. 화면 캡처 검증을 대신하는 테스트는 아닙니다.

## 학생 흐름 (현재 구현)

로그인 → **처음으로 학습하기 / 학습 이어서 하기** → (처음) 1학기/2학기 선택 → 단원 선택 → 그 단원의 선개념 단계로 바로 진입 → 7단계 순서대로 학습 → 단원 마침 → 다음 단원.

- **한 화면에 하나.** 각 단계는 화면 단위 ‘스텝’으로 나뉜다. 읽기 단계는 `####` 소제목 하나가 한 카드(길면 몇 문단씩 이어서), 평가 단계는 문항 하나가 한 카드. 상단에 진행 막대, 하단에 큰 주 행동 버튼(다음/확인) 하나. 전체 696화면(개념 395·문항 291·보충 10).
- **즉시 피드백.** 답을 고르고 ‘확인’을 누르면 그 자리에서 채점과 해설이 열린다. 선택형은 자동 채점, 서술형은 정답 기준을 보여 주고 자기 점검(맞게 썼어요/일부만/다시 공부)을 해야 다음으로 넘어간다. 키보드 1~5로 선지 선택, Enter로 주 행동.
- **보고 누르고 해 보기.** 정의·순서·그림 읽기·생각해 보기는 각각 다른 카드로 그려지고, 굵은 용어를 누르면 오른쪽에 용어 패널(정의·쓰인 문장·더 깊이·외부 검색)이 열린다. 개념 카드마다 아래에 상호작용 활동(위젯 11종)이 붙는다. 집필 활동은 `content/interactives/<unitId>.json`, 나머지는 자동 생성.
- 단계 끝에 요약(정답 수·다시 볼 문항), 단원 끝에 단원 요약과 다음 단원 버튼. `/learn/:unitId`는 7단계 경로 지도.
- 현재 위치(단계·화면 번호)·제출 기록·노트는 계정(uid)별로 저장되고 ‘학습 이어서 하기’로 복귀한다. ‘도움 · 노트’ 버튼으로 선수개념/내 노트 패널을 연다.

## 콘텐츠 규칙

- 원고를 요약하지 않는다. 단계 본문은 원고 문단을 그대로 렌더링한다.
- 편집자 출처 기록·재제작 프롬프트는 학생 화면에 넣지 않는다(변환 시 제외).
- 교과서·하이탑 원본 그림은 캡션 ‘원본 이미지 · 재제작 필요’, AI 생성 도판은 ‘AI 생성 도판(검토본)’, 자체 도해·평가원 원문은 출처 캡션을 그림 바로 아래에 표시한다.
- 교재 PDF·정답 원본 PDF·검수 장부는 저장소와 공개 폴더에 넣지 않는다.
