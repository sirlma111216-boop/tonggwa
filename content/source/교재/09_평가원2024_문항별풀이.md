# 평가원 2024 공개 통합과학 예시 — 문항별 심층 풀이

이 해설은 2024년에 공개된 통합과학 예시 12문항을 설명합니다. 실제로 시행된 수능 본시험의 기출과는 구별합니다. 문제는 「08 평가원 공식 예시 원문」 및 별도 원문 PDF에서 먼저 풀어 보세요. 이 문서에서는 원문의 조건·그림·선지를 바꾸지 않고, 판단 과정과 복습 지점을 설명합니다.

‘공식 평가 초점’은 평가원의 문항 정보와 평가 목표를 요약한 것입니다. ‘순서대로 풀기’, ‘실수 점검’, ‘다른 문제에 옮길 전략’은 그 근거를 바탕으로 집필한 자체 학습 해설입니다. 공식 정답과 자체 풀이를 구별합니다. 각 문항의 원문 이미지에 있는 표·그래프·그림·보기·선지를 직접 확인하고 원본 PDF의 공식 정답과 대조했습니다. 5번의 헤모글로빈 모형과 7번의 모형 실험에는 과학적으로 구분해서 읽어야 할 지점이 있어 해당 해설에 따로 설명했습니다.

## 01 같은 ‘핵’이라는 말, 다른 규모 [KICE-2024-Q01]

**공식 정답: ③ — 학생 A, B.** 원문 PDF48쪽, 공식 문항 정보·정답 PDF49쪽. 원문에 있는 지구핵·세포핵·리튬 원자핵 모형, 지름 x·y·z, 학생 세 명의 말을 모두 확인했다.

### 왜 묻는가

**공식 평가 초점:** 서로 다른 과학 분야의 대상을 비교하여 규모, 기본량, 단위를 이해하는지 평가한다. 행동 영역은 ‘이해’이다.

이름이 모두 ‘핵’이라고 같은 구조나 크기인 것은 아니에요. 이 문제는 그 이름에 끌려가지 않고 **지금 비교하는 양이 무엇인지** 찾는 연습입니다.

### 처음 확인할 조건

- x·y·z는 각각 핵의 **지름**이다. 표에 단위 m가 붙어 있다.
- 세 그림은 각 구조를 알아보기 위한 모형이다. 종이에 그려진 그림의 크기를 실제 크기의 비로 읽지 않는다.
- 학생 C는 지름에서 **부피**로 비교 대상을 바꾸었다.

### 순서대로 풀기

1. **지름은 길이이다.** 핵의 물질이나 기능이 달라도 두 끝 사이의 거리를 재는 양이라는 점은 같습니다. 길이는 기본량이므로 A의 설명은 옳아요.
2. **실제 규모를 비교한다.** 지구의 핵은 지구 내부 구조이고, 동물 세포의 핵은 세포 안 구조이며, 원자핵은 원자 안의 아주 작은 구조입니다. 따라서 x > y > z입니다. 정확한 지름 수치를 외우지 않아도 규모 순서를 판단할 수 있어요.
3. **부피의 단위를 분리한다.** 길이를 m로 나타내면 부피의 SI 단위는 m³입니다. 지름과 부피는 같은 단위로 표현되지 않습니다. C의 설명은 틀립니다.

**정의 점검:** 길이는 기본량이다. 부피는 길이를 세 번 곱한 차원의 유도량이다. 단위가 m라는 사실과 양의 이름이 길이라는 사실을 구별한다.

### 학생 발언과 선지의 판정

| 대상 | 판정과 이유 |
|---|---|
| A | 옳음. 세 핵의 지름은 모두 길이이다. |
| B | 옳음. 실제 규모는 지구핵 > 세포핵 > 원자핵이다. |
| C | 틀림. 지름은 m, 부피는 m³ 등으로 나타낸다. |
| ① A | B도 옳은데 빠져 있다. |
| ② C | 틀린 발언만 골랐다. |
| ③ A, B | 옳은 발언을 모두 고른 정답이다. |
| ④ B, C | 틀린 C를 포함하고 옳은 A를 빠뜨렸다. |
| ⑤ A, B, C | 틀린 C를 포함했다. |

### 실수 점검과 복습

그림 속 세 핵이 비슷하게 그려졌다는 이유로 크기도 비슷하다고 생각했다면 모형과 실제의 차이를 놓친 거예요. ‘같은 대상의 지름과 부피’라는 이유로 단위도 같다고 생각했다면 양의 종류를 먼저 분리해야 합니다. 돌아갈 곳은 **01 과학의 기초의 ‘자연 세계의 시간과 공간’, ‘기본량과 단위’**입니다.

### 다른 문제에 옮길 전략

**대상 이름 → 재는 양 → 단위 → 규모**의 순서로 읽습니다. 같은 종류의 길이를 비교할 때는 공통 단위로 바꾸면 됩니다. 지름·넓이·부피가 섞이면 그대로 수치만 비교하지 않습니다. 종이 위 크기를 실제 크기로 쓰려면 축척이 제시되어야 합니다.

## 02 밝은 선과 어두운 선을 같은 위치에서 비교하기 [KICE-2024-Q02]

**공식 정답: ① — ㄱ.** 원문 PDF50쪽, 공식 문항 정보 PDF51–52쪽. 수소·헬륨·탄소의 방출선과 별 S의 흡수선의 위치, 동일한 파장 영역이라는 조건, 세 보기를 확인했다.

### 왜 묻는가

**공식 평가 초점:** 원소의 스펙트럼과 별의 흡수 스펙트럼을 비교하여 구성 물질을 파악하고 원소의 형성 역사와 연결한다. 행동 영역은 ‘자료 변환 및 해석’이다.

별에 직접 가서 물질을 가져오지 않아도 빛에서 단서를 얻을 수 있어요. 이 문제에서 필요한 것은 선의 화려한 색이 아니라 **가로 위치가 일치하는지**입니다.

### 처음 확인할 조건

- (가)는 고온의 기체 방전관에서 관찰한 자료이다.
- (나)는 별 S의 **흡수** 스펙트럼이다.
- 관측한 파장 영역은 같다. 같은 가로 위치를 비교할 수 있다.
- ㄴ의 ‘더 풍부’는 존재 여부보다 강한 양적 주장이고, ㄷ의 ‘모두’는 다른 기원을 배제하는 주장이다.

### 순서대로 풀기

1. **밝은 선과 어두운 선의 의미를 구별한다.** (가)의 어두운 바탕에 나타나는 밝은 선은 방출선입니다. 별빛의 연속적인 바탕에서 어두워진 위치는 흡수선입니다. 두 선은 밝기가 반대여도 원소가 빛을 흡수·방출하는 파장 정보를 비교하는 데 사용할 수 있습니다.
2. **행을 수직으로 맞춰 읽는다.** 별의 어두운 선 위치를 위의 원소별 밝은 선 위치와 대조하면 수소·헬륨의 특징적인 선들과 대응합니다. 탄소가 헬륨보다 풍부하다는 결론은 이 자료에서 얻을 수 없어요. 특히 선의 개수나 전체 그림의 진하기를 곧바로 원소 함량으로 바꾸는 것은 적절하지 않습니다.
3. **현재 별에 들어 있는 원소와 그 별이 만든 원소를 구분한다.** 별은 형성될 때 이미 있던 원소를 재료로 삼습니다. 헬륨은 초기 우주에서도 만들어졌습니다. 그러므로 별 속 헬륨을 전부 별 내부 핵융합의 산물이라고 단정할 수 없습니다.

**정의 점검:** 방출선은 특정 파장에서 빛의 세기가 강하게 나타나는 선이며, 흡수선은 연속 스펙트럼에서 특정 파장의 세기가 상대적으로 약해진 선이다.

### 보기와 선지의 판정

| 대상 | 판정과 이유 |
|---|---|
| ㄱ | 옳음. 고온 수소 기체의 밝은 선은 방출선이다. |
| ㄴ | 틀림. 탄소가 헬륨보다 풍부하다는 자료 근거가 없다. 제시된 흡수선의 위치 비교는 수소·헬륨과의 대응을 보여 준다. |
| ㄷ | 틀림. 헬륨은 초기 우주에도 기원을 두므로 ‘모두 별 내부’로 한정할 수 없다. |
| ① ㄱ | 정답이다. |
| ② ㄴ | 틀린 보기만 골랐다. |
| ③ ㄱ, ㄷ | 틀린 ㄷ을 추가했다. |
| ④ ㄴ, ㄷ | 두 보기 모두 틀리다. |
| ⑤ ㄱ, ㄴ, ㄷ | 틀린 ㄴ·ㄷ을 포함했다. |

### 실수 점검과 복습

‘어두운 선이므로 빛의 정보가 없다’고 생각하면 흡수의 의미를 복습하세요. ‘별에 있으니 별에서 전부 만들어졌다’고 생각했다면 재료의 기원과 현재 위치를 혼동한 것입니다. 돌아갈 곳은 **02 물질과 규칙성의 ‘빛으로 읽는 원소와 초기 우주’, ‘별에서 지구와 생명체까지’**입니다.

### 다른 문제에 옮길 전략

먼저 **선의 위치로 후보를 판단**하고, 함량 비교는 별도의 정량 자료가 있는지 확인합니다. 실제 관측에서는 관측 범위·검출 한계·기체 상태·파장 이동도 영향을 줄 수 있습니다. 따라서 ‘일부 선이 안 보임 → 해당 원소가 절대로 없음’으로 일반화하지 않습니다. 초기 우주·별 내부·물질 방출이라는 생성과 이동의 경로를 함께 확인합니다.

## 03 한 운동을 수평과 연직으로 나누어 읽기 [KICE-2024-Q03]

**공식 정답: ⑤ — ㄱ, ㄴ, ㄷ.** 원문 PDF53쪽, 공식 문항 정보 PDF54–55쪽. 발사 장치에서 A를 놓고 B를 수평으로 발사하는 모습, 그래프Ⅰ의 이동 거리 축, Ⅱ·Ⅲ의 속력 축을 모두 확인했다.

### 왜 묻는가

**공식 평가 초점:** 디지털 도구로 물체 운동을 기록하고, 수집한 자료를 그래프로 표현·해석한다. 행동 영역은 ‘탐구 수행 및 자료 수집’이다.

실험 그림에서 B가 옆으로 날아간다는 사실이 눈에 들어와요. 하지만 옆으로 가는 운동이 아래로 떨어지는 운동을 없애지는 않습니다. 두 방향을 따로 읽는 것이 출발점이에요.

### 처음 확인할 조건

- A는 가만히 놓고 B는 **수평 방향**으로 발사한다. 두 물체의 초기 연직 속력은 0으로 비교한다.
- Ⅰ의 세로축은 이동 거리, Ⅱ·Ⅲ의 세로축은 속력이다.
- 공식 해설에서 적용하는 지표 부근의 이상화된 운동 모형은 공기 저항 등의 영향을 무시하고 중력에 의한 연직 운동과 수평 등속 운동을 비교하는 것이다.

### 순서대로 풀기

1. **A의 연직 운동을 생각한다.** 가만히 놓은 A는 중력 때문에 아래쪽 속력이 계속 커집니다. 같은 시간 동안 이동하는 거리가 점점 길어지므로 전체 이동 거리-시간 그래프는 점점 가팔라져요. 따라서 Ⅰ과 대응합니다.
2. **B의 수평 운동을 분리한다.** 이 모형에서 B는 수평 방향 속력이 일정합니다. 시간에 따라 일정한 양의 값을 유지하는 속력 그래프가 Ⅱ예요. Ⅱ의 그래프가 수평이라고 물체가 멈춘다는 뜻은 아닙니다. 속력이 0이 아닌 일정한 값이라는 뜻입니다.
3. **B의 연직 운동을 A와 비교한다.** B도 처음 연직 속력이 0이고 같은 중력을 받습니다. 따라서 연직 속력은 시간에 따라 일정한 비율로 증가하여 Ⅲ처럼 나타나며, 연직 이동 거리는 Ⅰ처럼 나타납니다.
4. **같은 운동도 축이 다르면 그래프 모양이 다르다.** B의 연직 운동을 이동 거리로 그리면 Ⅰ, 속력으로 그리면 Ⅲ입니다. 둘 중 하나만 고를 필요가 없어요.

수식을 이용해 확인한다면 연직 속력은 시간에 비례하고, 연직 이동 거리는 시간의 제곱에 비례합니다. 그러나 이 문항은 복잡한 포물선 공식을 새로 세우지 않아도 축과 속력의 변화로 판단할 수 있습니다.

### 보기와 선지의 판정

| 대상 | 판정과 이유 |
|---|---|
| ㄱ | 옳음. A의 연직 이동 거리 증가가 점점 빨라져 Ⅰ과 맞는다. |
| ㄴ | 옳음. B의 수평 속력은 일정하여 Ⅱ와 맞는다. |
| ㄷ | 옳음. B의 연직 이동 거리는Ⅰ, 연직 속력은Ⅲ으로 나타낼 수 있다. |
| ① ㄱ | 옳은 ㄴ·ㄷ을 빠뜨렸다. |
| ② ㄷ | 옳은 ㄱ·ㄴ을 빠뜨렸다. |
| ③ ㄱ, ㄴ | 옳은 ㄷ을 빠뜨렸다. |
| ④ ㄴ, ㄷ | 옳은 ㄱ을 빠뜨렸다. |
| ⑤ ㄱ, ㄴ, ㄷ | 세 보기가 모두 옳아 정답이다. |

### 실수 점검과 복습

Ⅱ를 정지라고 읽었다면 속력-시간과 위치-시간 그래프를 혼동한 거예요. B가 수평으로 움직이므로 연직으로는 천천히 떨어진다고 생각했다면 두 방향 운동의 독립적 비교가 필요합니다. 돌아갈 곳은 **03 시스템과 상호작용의 중력과 운동 소단원**, 그리고 **01 과학의 기초의 그래프 축·단위 읽기**입니다.

### 다른 문제에 옮길 전략

**방향 → 측정량 → 시간에 따른 변화 → 그래프 모양**의 순서를 따릅니다. 수평 속력이 일정하다는 결론은 수평으로 힘이 작용하지 않는 출제 모형에서 적용합니다. 공기 저항·바람·추진력이 제시되면 조건을 다시 확인해야 합니다. 곡선의 모양만 보고 이름부터 붙이지 않습니다.

## 04 코일 위의 접근과 아래의 이탈을 구별하기 [KICE-2024-Q04]

**공식 정답: ③ — ㄱ, ㄴ.** 원문 PDF56쪽, 공식 문항 정보 PDF57–58쪽. 자석의 N극이 아래를 향하는 배치, 코일 위 p와 아래 q, 높이 h, (다)에서 검류계가 +쪽으로 움직인 그림을 확인했다.

### 왜 묻는가

**공식 평가 초점:** 낙하하는 자석의 운동과 전자기 유도를 연결하여 에너지 전환, 전류의 크기·방향에 관한 결론을 도출한다. 행동 영역은 ‘결론 도출 및 일반화’이다.

이 문제에서는 ‘N극’과 ‘S극’이라는 글자만 보고 방향 표를 적용하면 오히려 틀리기 쉬워요. **코일의 어느 쪽에서, 자석 전체가 어떻게 지나가는지**를 먼저 보아야 합니다.

### 처음 확인할 조건

- 같은 자석을 N극이 아래를 향하도록 놓는다. 극의 방향을 뒤집지 않는다.
- (다)는 N극이 **코일 위 p**를 지나며 접근하는 단계이다.
- (라)는 S극이 **코일 아래 q**를 지나며 자석이 빠져나간 단계이다.
- (다)의 + 방향이 기준이며 도선 연결은 그대로이다.

### 순서대로 풀기

1. **에너지의 출발과 도착을 찾는다.** 자석이 내려오면서 중력에 의한 위치 에너지가 줄고 운동 에너지가 생깁니다. 코일에 전류가 유도되는 동안 자석의 역학적 에너지 일부가 전기 에너지로 전환됩니다. 전기가 아무 에너지 공급 없이 생기는 것이 아니에요.
2. **높이 h와 p에서의 속력을 연결한다.** 같은 자석을 더 높은 곳에서 가만히 놓으면 p까지 더 긴 거리를 낙하합니다. 공식 출제 모형에서는 p에서 속력이 더 커지고, 코일을 지나는 자기장 변화도 더 빠르게 일어납니다. 방향 조건은 같으므로 +쪽으로 더 크게 움직입니다. 정확히 몇 배인지는 주어지지 않았으므로 계산하지 않습니다.
3. **접근과 이탈에서 자기장 변화가 반대임을 읽는다.** 자석이 코일로 들어올 때는 코일을 통과하는 자기적 영향이 증가하고, 완전히 빠져나가 멀어질 때는 감소합니다. 유도 전류는 그 변화에 대응하므로 방향이 바뀝니다. (다)가 +이면 (라)는 −입니다.
4. **단순한 두 번 뒤집기 규칙을 적용하지 않는다.** ‘N접근은 +, 그러면 S이탈도 +’라는 표는 코일의 **같은 쪽**에서 자석의 극과 움직임만 바꿔 비교할 때 사용하는 형태입니다. 이 문제의 p와 q는 코일의 반대쪽입니다. 같은 자석의 N극이 먼저 들어가고 S극이 나중에 아래로 빠져나간 것이므로 그 표를 글자만으로 적용할 수 없어요.

### 보기와 선지의 판정

| 대상 | 판정과 이유 |
|---|---|
| ㄱ | 옳음. 자석의 역학적 에너지 일부가 전기 에너지로 전환된다. |
| ㄴ | 옳음. 같은 장치의 출제 모형에서 h가 크면 p에서 더 빠르게 접근하여 +방향 유도 효과가 커진다. |
| ㄷ | 틀림. 자석이 코일을 통과해 멀어지는 (라)는 (다)와 반대인 −방향이다. |
| ① ㄱ | 옳은 ㄴ이 빠졌다. |
| ② ㄷ | 틀린 보기만 골랐다. |
| ③ ㄱ, ㄴ | 정답이다. |
| ④ ㄴ, ㄷ | 틀린 ㄷ을 포함하고 옳은 ㄱ을 빠뜨렸다. |
| ⑤ ㄱ, ㄴ, ㄷ | 틀린 ㄷ을 포함했다. |

### 실수 점검과 복습

자석이 계속 아래로 이동하니 전류 방향도 같다고 생각했다면 **운동 방향**과 **코일을 통과하는 자기장 변화**를 구별해야 합니다. N·S만 두 번 뒤집어 ㄷ을 골랐다면 p·q의 위치가 핵심이에요. 돌아갈 곳은 **05 환경과 에너지의 ‘전자기 유도와 발전’**, **03 시스템과 상호작용의 낙하 운동**입니다.

### 다른 문제에 옮길 전략

자석의 극에 앞서 **코일의 위치·접근하는 쪽·이탈하는 쪽·회로 연결**을 고정해 읽습니다. 높이로 전류 크기를 비교하려면 자석·코일·경로·저항 등의 조건이 같아야 합니다. 높이가 같다는 사실이 모든 실험에서 질량이나 운동 에너지까지 같게 만든다는 뜻은 아닙니다.

## 05 사례와 어긋나지 않는 가설 찾기 [KICE-2024-Q05]

**공식 정답: ⑤ — ㄴ, ㄷ.** 원문 PDF59쪽, 공식 문항 정보·정답 PDF60쪽. 호상철광층·광합성·헤모글로빈 그림과 반응식, 열 출입 표의 빈칸, 가설의 ㉠과 결론을 확인했다. 아래의 ㄷ 판정은 공식 문항이 사용한 산소 결합 모형에 따른 것이며, 생리학적 산소화와 일반적인 철의 산화를 동일시하지 않는다.

### 왜 묻는가

**공식 평가 초점:** 산화·환원과 에너지 출입의 사례를 비교하여 적절한 가설을 설정하고 자료로 검토한다. 행동 영역은 ‘문제 인식 및 가설 설정’이다.

어떤 사례 두 개에서 같은 결과가 나왔다고 나머지 사례까지 모두 같다고 단정할 수는 없어요. 여기서는 **가설이 조사한 사례 전체와 양립하는지** 확인해야 합니다.

### 처음 확인할 조건

- 학생의 결론은 가설이 옳다는 것이다. 따라서 ㉠에는 제시된 사례와 어긋나는 일반화를 넣을 수 없다.
- (가)와 (다)에 방출이 제시되어도 (나)의 광합성까지 같은 과정이라고 볼 수 없다.
- ㄴ은 철의 전자 이동을, ㄷ은 문항의 Hb와 산소 결합 모형을 묻는다. 두 사례의 설명 수준을 구분한다.

### 순서대로 풀기

1. **‘모든 사례에서 열을 방출한다’는 후보를 시험한다.** 광합성은 빛에너지를 공급받아 유기물에 에너지를 저장하는 과정입니다. (가)와 (다)의 방출 표시만 보고 모든 산화·환원이 주위로 열을 방출한다는 공통 가설을 채택할 수 없어요. ㄱ은 옳지 않습니다. 광합성에서 빛에너지를 흡수한다는 설명과 열이 이동한다는 설명을 완전히 같은 뜻으로 외우지는 않습니다.
2. **철의 반응을 산화와 연결한다.** (가)에서 철은 산소와 결합하여 산화 철을 이룹니다. 산소를 얻는 산화이며, 전자 이동의 관점에서는 철이 전자를 잃는 방향입니다. ㄴ은 옳습니다. 여기서 선택과목의 산화수 계산을 새로 도입하지 않아도 철이 양이온 성격을 갖는 산화물에 들어감을 이해할 수 있어요.
3. **Hb의 보기를 원문의 모형과 공식 판정으로 읽는다.** 원문은 Hb가 O₂와 결합하여 HbO₂가 되는 현상을 산소를 얻는 모형으로 다루고 ㄷ을 옳다고 판정했습니다. 따라서 공식 답안에서는 ㄴ·ㄷ을 고릅니다.

**과학적 구별:** 실제 헤모글로빈의 정상적인 산소 결합은 ‘산소화’라고 하며, 산소를 운반하는 결합과 철이 산화되어 메트헤모글로빈이 되는 현상을 같은 과정으로 설명하면 안 됩니다. 이 문항의 단순화된 표현을 근거로 ‘산소가 붙으면 생체 분자는 모두 같은 방식으로 전자를 잃는다’는 규칙을 만들지 마세요. 산소화와 산화 경로를 구별해야 한다는 점은 전문 문헌에서도 설명합니다. [헤모글로빈 산소화와 산화 반응의 구별](https://pmc.ncbi.nlm.nih.gov/articles/PMC4047995/)

### 보기와 선지의 판정

| 대상 | 판정과 이유 |
|---|---|
| ㄱ | 틀림. 광합성을 포함한 사례 전체를 ‘주위로 열 방출’ 하나로 묶을 수 없다. |
| ㄴ | 옳음. 철은 산화되며 전자를 잃는 방향의 변화이다. |
| ㄷ | 공식 판정에서 옳음. 제시된 산소 결합 모형에 따른 판정이다. 실제 산소화와 메트헤모글로빈 형성을 혼동하지 않는다. |
| ① ㄱ | 틀린 가설 후보만 골랐다. |
| ② ㄴ | 공식 판정상 옳은 ㄷ을 빠뜨렸다. |
| ③ ㄷ | 옳은 ㄴ을 빠뜨렸다. |
| ④ ㄱ, ㄴ | 틀린 ㄱ을 포함하고 ㄷ을 빠뜨렸다. |
| ⑤ ㄴ, ㄷ | 공식 정답이다. |

### 실수 점검과 복습

ㄱ을 골랐다면 빈칸에 그럴듯한 말을 넣기 전에 **모든 사례에 대입**하는 단계가 필요합니다. ㄴ을 틀렸다면 산소를 얻는 산화와 전자를 잃는 산화를 연결하세요. 돌아갈 곳은 **04 변화와 다양성의 산화·환원, 에너지 출입 소단원**입니다. Hb의 전문적인 산화 상태를 이 문항을 풀기 위한 추가 암기 과제로 삼지는 않습니다.

### 다른 문제에 옮길 전략

‘모든’, ‘항상’이 들어가는 가설은 한 사례씩 대입하여 반례를 찾습니다. 한 사례가 맞는다는 것과 가설이 모든 경우에 성립한다는 것은 다릅니다. 출제 모형의 단순화는 그 문항의 답안 판단과 구분하여 기록하고, 다음 개념 설명에 무제한으로 옮기지 않습니다.

## 06 이온 그림에서 농도비를 찾아 세 혼합물을 복원하기 [KICE-2024-Q06]

**공식 정답: ⑤ — ㄴ, ㄷ.** 원문 PDF61쪽, 공식 문항 정보·정답 PDF62쪽. 혼합 부피 표, BTB 파란색, Ⅱ의 이온 모형(한 기호 4개와 나머지 두 기호 각각 2개), Ⅰ의 총이온 수 12N, 동일한 초기 온도와 부피 합 조건을 직접 확인했다.

### 왜 묻는가

**공식 평가 초점:** 중화 전후의 이온 종류와 수를 모형으로 해석하고, 혼합 용액의 온도·색·총이온 수를 수학적으로 추론한다. 행동 영역은 ‘결론 도출 및 일반화’이다.

처음부터 Ⅰ·Ⅱ·Ⅲ을 모두 계산하려고 하면 복잡해 보여요. 정보가 가장 많은 **Ⅱ의 색과 입자 수**에서 시작하면 두 원액의 관계가 먼저 밝혀집니다.

### 처음 확인할 조건

- Ⅱ는 HCl 10 mL와 NaOH 10 mL를 혼합한 용액이다. 부피는 같지만 두 원액의 농도가 같다는 뜻은 아니다.
- Ⅱ의 BTB 색은 파란색이다. 따라서 OH⁻가 남은 염기성이다.
- H⁺와 OH⁻는 1:1로 반응하여 물이 된다. Na⁺와 Cl⁻는 이 반응에서 없어지지 않는 이온이다.
- 세 혼합 용액의 전체 부피는 모두 20 mL이며 혼합 전 온도가 같다.

### 순서대로 풀기

#### 1단계: Ⅱ에서 어떤 이온이 남았는지 정한다

Ⅱ가 염기성이므로 남은 이온은 Na⁺, Cl⁻, OH⁻입니다. 세 종류가 모두 전하량 크기 1인 이온이므로, 전기적으로 중성인 용액에서는 **Na⁺ 수 = Cl⁻ 수 + OH⁻ 수**가 되어야 합니다.

원문의 그림에는 네모가 4개, 동그라미가 2개, 세모가 2개 있습니다. 가장 많은 네모 4개가 Na⁺이고 나머지 두 기호는 Cl⁻와 OH⁻에 대응합니다. 동그라미와 세모 중 어느 것이 Cl⁻인지는 이 그림만으로 정할 필요가 없어요. 둘의 수가 같다는 관계를 쓰면 충분합니다.

#### 2단계: 같은 부피에 들어 있는 반응 이온 수의 비를 구한다

Ⅱ에서 Cl⁻의 수는 처음 HCl이 공급한 H⁺ 수와 같습니다. Na⁺의 수는 처음 NaOH가 공급한 OH⁻ 수와 같아요. 따라서 같은 부피 10 mL에서 NaOH가 공급하는 OH⁻ 수는 HCl이 공급하는 H⁺ 수의 2배입니다.

**기준 설정:** HCl 1 mL에 들어 있는 H⁺ 수를 a라고 두면, 같은 부피의 Cl⁻도 a이다. NaOH 1 mL에는 Na⁺와 OH⁻가 각각 2a씩 있다.

#### 3단계: 각 용액의 반응 전·후를 표로 정리한다

| 혼합 용액 | 처음 H⁺ 수 | 처음 OH⁻ 수 | 반응한 쌍 수 | 반응 후 남는 이온 |
|---|---:|---:|---:|---|
| Ⅰ: HCl15 mL + NaOH5 mL | 15a | 10a | 10a | H⁺5a, Cl⁻15a, Na⁺10a |
| Ⅱ: HCl10 mL + NaOH10 mL | 10a | 20a | 10a | OH⁻10a, Cl⁻10a, Na⁺20a |
| Ⅲ: HCl5 mL + NaOH15 mL | 5a | 30a | 5a | OH⁻25a, Cl⁻5a, Na⁺30a |

H⁺와 OH⁻ 중 더 적은 쪽이 반응할 수 있는 쌍의 수를 정합니다. 예를 들어 Ⅲ에서는 OH⁻가 많이 있어도 H⁺가 5a뿐이므로 5a쌍만 반응합니다. 남는 OH⁻는 30a−5a=25a예요.

#### 4단계: 색과 온도를 판정한다

Ⅰ에는 H⁺가 남으므로 산성입니다. 따라서 ㉠은 파란색이 아닙니다. BTB의 산성 색인 노란색으로 판단합니다.

Ⅰ에서 반응한 쌍은 10a, Ⅲ에서는 5a입니다. 같은 초기 온도와 같은 전체 부피를 비교하는 이 문항의 열적 모형에서는 반응한 양이 많은 Ⅰ의 최고 온도가 더 높으므로 t₁ > t₂입니다. **원래 넣은 산의 부피만으로 온도를 정한 것이 아니라 실제 반응한 양을 비교한 것**입니다. 서로 다른 총부피나 열손실 조건을 가진 실험에는 이 비교를 그대로 적용하지 않습니다.

#### 5단계: 실제 척도 N을 연결한다

Ⅰ의 모든 이온 수는 5a+15a+10a=30a이며 문제에서 12N이라고 주었습니다. 따라서 a=(2/5)N입니다.

- Ⅱ의 모든 이온 수 x=10a+10a+20a=40a=16N.
- Ⅲ의 모든 이온 수 y=25a+5a+30a=60a=24N.
- 따라서 x+y=40N입니다.

물 분자는 ‘모든 이온 수’에 포함하지 않습니다. 반응한 H⁺와 OH⁻를 반응 후 이온 수에 다시 더하는 것도 피해야 합니다.

### 실수 점검과 복습

같은 10 mL를 섞었으니 중성이라고 생각했다면 부피와 이온 수를 혼동한 것입니다. 그림의 기호를 원소 이름에 임의로 붙였다면 전하 중성 조건으로 가장 많은 이온부터 찾으세요. x+y에서 40a를 답했다면 a와 N의 척도 연결을 빠뜨린 거예요. 돌아갈 곳은 **04 변화와 다양성의 산·염기와 중화**, **01 과학의 기초의 비와 단위 부피당 양**입니다.

### 다른 문제에 옮길 전략

**지시약 → 남은 반응 이온 → 전하 중성 → 원액 비 → 각 혼합물 복원**의 순서를 사용합니다. 이 방법은 원액이 HCl과 NaOH이며 제시된 이온이 각각 완전히 해리된 모형에서 적용한 것입니다. 다른 산·염기나 여러 종류 원액이 제시되면 이온의 전하와 공급 비율부터 다시 정합니다. 최고 온도 비교에는 반응량뿐 아니라 전체 용액량·초기 온도·열손실 조건도 확인합니다.

## 07 모형 실험의 결과와 지구 복사 평형 연결하기 [KICE-2024-Q07]

**공식 정답: ⑤ — ㄱ, ㄴ, ㄷ.** 원문 PDF63쪽, 공식 문항 정보·정답 PDF64쪽. 두 병의 부피·초기 물 온도·물의 양, B에만 고체를 넣은 조건, 전등 거리, 온도 그래프의 점선㉠·실선㉡, 결론의 빈칸을 확인했다.

### 왜 묻는가

**공식 평가 초점:** 이산화 탄소 농도 차이와 온도 변화에 관한 모형 실험 결과를 온실 효과 및 복사 평형에 연결한다. 행동 영역은 ‘결론 도출 및 일반화’이다.

그래프가 올라가는지만 보는 문제가 아니에요. 어느 병을 어떤 조건으로 처리했는지, 어느 곡선이 더 높은 온도에 도달하는지, 그 결과를 지구에 어떤 개념으로 연결하는지 차례로 읽어야 합니다.

### 처음 확인할 조건

- A와 B의 병 부피, 처음 물 온도와 물의 양, 전등과의 거리를 같게 두었다.
- B에만 물과 반응하여 CO₂를 만드는 고체를 넣었다.
- ㉠은 위쪽 점선, ㉡은 아래쪽 실선이다. 두 곡선은 처음에는 같은 온도에서 출발한다.
- 보기의 지구 설명은 온실 기체 증가와 새로운 복사 평형을 연결한다.

### 순서대로 풀기

1. **처리 집단을 찾는다.** 문항이 의도한 비교에서 CO₂가 더 많은 병은 B입니다. 공식 출제 모형에서는 더 높은 온도 곡선㉠을 B에 대응시킵니다. ㄱ은 옳습니다.
2. **온도 차를 온실 효과의 변화로 해석한다.** 온실 기체는 지표가 방출하는 적외선의 일부를 흡수하고 다시 방출합니다. 양이 증가하면 같은 온도에서 우주로 나가는 에너지와 들어오는 에너지 사이의 균형이 달라질 수 있어요. 따라서 결론의 빈칸은 온실 효과가 ‘강화’된다는 방향입니다.
3. **온도 상승과 새 평형을 연결한다.** 에너지가 축적되면 지표와 대기가 따뜻해지고, 복사 방출도 달라집니다. 새 평형에서는 흡수량과 방출량이 다시 균형을 이루지만 그때의 온도는 이전보다 높을 수 있어요. ‘평형’은 온도가 반드시 처음 값으로 돌아간다는 뜻이 아닙니다.

**실험 모형의 한계:** 이 문항의 정답은 제시된 모형과 공식 해석을 따릅니다. 실제 실험을 다시 설계한다면 B에 넣은 고체가 물과 반응할 때의 열 출입, 기체 발생에 따른 다른 변화, 측정 위치 등을 추가로 통제해야 합니다. 병에서 온도 차가 났다는 관찰 하나만으로 모든 차이가 CO₂의 복사 효과 때문이라고 독립적으로 입증했다고 말하지 않습니다. 이 제한은 공식 정답을 바꾸라는 뜻이 아니라, 모형의 적용 범위를 정확히 이해하자는 뜻입니다.

### 보기와 선지의 판정

| 대상 | 판정과 이유 |
|---|---|
| ㄱ | 공식 출제 모형에서 옳음. CO₂를 추가한 B가 더 높은 온도의㉠과 대응한다. |
| ㄴ | 옳음. CO₂ 증가에 따른 온실 효과의 강화로 해석한다. |
| ㄷ | 옳음. 온실 효과 강화 이후 더 높은 온도에서 새 복사 평형에 도달할 수 있다. |
| ① ㄱ | 옳은 ㄴ·ㄷ을 빠뜨렸다. |
| ② ㄷ | 옳은 ㄱ·ㄴ을 빠뜨렸다. |
| ③ ㄱ, ㄴ | 옳은 ㄷ을 빠뜨렸다. |
| ④ ㄴ, ㄷ | 옳은 ㄱ을 빠뜨렸다. |
| ⑤ ㄱ, ㄴ, ㄷ | 공식 정답이다. |

### 실수 점검과 복습

그래프가 나중에 거의 수평이 된 것을 보고 열이나 에너지의 출입이 모두 멈췄다고 생각했다면 평형을 다시 보세요. 서로 반대인 출입이 균형을 이룰 수 있습니다. 돌아갈 곳은 **05 환경과 에너지의 지구 환경 변화·복사 평형**, **01 과학의 기초의 측정 조건과 변인 통제**입니다.

### 다른 문제에 옮길 전략

**통제 조건 → 바꾼 조건 → 그래프 대응 → 에너지 출입 → 결론의 범위**를 확인합니다. 같은 모양의 그래프라고 온실 효과 실험으로 확정하지 않습니다. 실제 실험과 지구 전체의 복사 평형은 규모·열 전달 경로가 다르므로, 모형이 보여 주는 관계와 보여 주지 못하는 관계를 구분합니다.

## 08 출력의 크기와 효율을 구별하기 [KICE-2024-Q08]

**공식 정답: ③ — 학생 A, C.** 원문 PDF65쪽, 공식 문항 정보 PDF66–67쪽. 내연 기관차와 전기차의 입력·열·장치용 전기·주행 에너지 화살표, E₀ 계수, 학생 발언을 확인했다.

### 왜 묻는가

**공식 평가 초점:** 에너지 전환과 효율에 관한 자료를 근거로 과학적 주장을 판단한다. 행동 영역은 ‘의사소통’이다.

20이 16보다 크다는 계산은 맞지만, 그것만으로 효율까지 더 크다고 말하면 안 돼요. 효율은 **얼마를 넣어 얼마를 얻었는가**를 묻는 비율입니다.

### 처음 확인할 조건

- 내연 기관차는100E₀, 전기차는25E₀를 공급받았다. 입력이 다르다.
- 여기서 유용한 출력의 기준은 **주행에 사용하는 에너지**이다.
- 장치에 필요한 전기 에너지 E₀는 주행 에너지와 별도로 표시되어 있다.
- 학생 C의 비교에는 ‘같은 양을 공급받음’이라는 조건이 있다.

### 순서대로 풀기

1. **에너지 합부터 점검한다.** 내연 기관차는79+1+20=100, 전기차는8+1+16=25입니다. 그림은 에너지 보존과 양립합니다. 버린 열도 에너지이므로 합에서 지우지 않습니다.
2. **주행 효율을 각각 계산한다.** 내연 기관차는20E₀/100E₀=0.20, 즉20%입니다. 전기차는16E₀/25E₀=0.64, 즉64%예요. E₀는 같은 단위이므로 비에서 약분됩니다. 전기차의 주행 출력이16으로 더 작아도 입력 대비 비율은 더 큽니다.
3. **화석 연료의 연소를 연결한다.** 자료의 화석 연료에는 탄소가 들어 있습니다. 연소에서 CO₂ 같은 온실 기체가 발생하므로 A의 발언은 옳습니다. 다만 여기서 전기차의 전기 생산·차량 제조까지 모두 환경 영향0이라고 결론 내리는 것은 다른 문제입니다.
4. **같은 입력에서 손실을 비교한다.** 이 문항이 다루는 사용 조건에서 같은 에너지를 넣고 버리는 열이 커지면 주행에 사용할 몫은 줄어 효율이 낮아집니다. C의 발언은 이 에너지 배분 관계에 대한 것입니다.

### 학생 발언과 선지의 판정

| 대상 | 판정과 이유 |
|---|---|
| A | 옳음. 자료의 화석 연료 연소는 CO₂ 등 온실 기체 발생과 연결된다. |
| B | 틀림. 주행 효율은 내연 기관차20%, 전기차64%로 전기차가 더 크다. |
| C | 옳음. 같은 입력과 비교하는 사용 조건에서 열로 버리는 몫이 커지면 유용한 몫의 비가 작아진다. |
| ① A | 옳은 C를 빠뜨렸다. |
| ② B | 효율을 잘못 비교한 발언이다. |
| ③ A, C | 정답이다. |
| ④ B, C | 틀린 B를 포함하고 옳은 A를 빠뜨렸다. |
| ⑤ A, B, C | 틀린 B를 포함했다. |

### 실수 점검과 복습

B를 골랐다면 출력의 절댓값20·16만 비교했는지 확인하세요. 효율에서21/100이나17/25를 계산했다면 주행 목적과 장치 사용량을 섞은 것입니다. 돌아갈 곳은 **05 환경과 에너지의 효율·에너지 보존**, **01 과학의 기초의 비율**입니다.

### 다른 문제에 옮길 전략

**목적을 정한 출력/그 장치의 입력**을 각각 계산합니다. 입력이 다르면 손실량 절댓값만으로 효율을 정하지 않습니다. 열 외의 출력 항목이나 저장 에너지가 별도로 변하는 문제에서는 그것까지 포함해 보존 관계를 써야 합니다. 주행 단계의 효율만으로 생산·폐기를 포함한 전체 환경 영향을 확정하지 않습니다.

## 09 두 가설에는 서로 다른 대조쌍이 필요하다 [KICE-2024-Q09]

**공식 정답: ⑤ — ㄱ, ㄴ, ㄷ.** 원문 PDF68쪽, 공식 문항 정보·정답 PDF69쪽. 네 홈 A~D의 용액·첨가물, 가설1·2, 기포와 색 표를 확인했다. B의 색깔은 원문에서도 물음표이므로 임의로 채우지 않았다.

### 왜 묻는가

**공식 평가 초점:** 효소의 기능·물질의 결합에 관한 개념을 사용하여 가설을 검증할 대조실험을 설계한다. 행동 영역은 ‘탐구 설계’이다.

네 홈을 한꺼번에 비교하면 복잡해요. 먼저 ‘효소가 있나?’와 ‘용액이 산성인가?’라는 **두 질문을 분리**하면 어느 쌍을 비교할지 보입니다.

### 처음 확인할 조건

- A와 B에는 모두 과산화 수소수가 있고, A에는 증류수, B에는 감자즙을 넣었다.
- C와 D에는 모두 BTB가 있고, C의 시험 용액은 과산화 수소수, D는 증류수이다.
- 기포 생성과 지시약 색은 서로 다른 관찰 결과이다.
- ㄱ의 ⓐ는 반응을 촉진하는 효소를 가리킨다.

### 순서대로 풀기

1. **가설1을 위한 비교를 찾는다.** A와 B를 비교하면 같은 과산화 수소수에 감자즙이 들어간 경우 기포가 관찰됩니다. 감자즙 속 효소가 분해 반응을 촉진한다는 설명과 연결됩니다. 효소는 반응이 진행되는 경로의 활성화 에너지를 낮춥니다. 반응물처럼 계속 소모되어야 하는 물질로 설명하지 않습니다.
2. **기포 물질을 결합과 연결한다.** 과산화 수소 분해에서는 물과 산소가 생성됩니다. 산소 O₂에서는 산소 원자들이 전자쌍을 공유하므로 공유 결합 물질입니다. ‘같은 원소끼리 결합했으니 결합이 없다’고 생각하면 안 돼요.
3. **가설2를 위한 비교를 찾는다.** C와 D에는 같은 지시약을 넣습니다. C가 노란색, D가 녹색이므로 제시된 과산화 수소수의 산성 여부를 비교할 수 있습니다. 감자즙의 효소 기능과 지시약 색을 한 비교쌍으로 뒤섞지 않습니다.
4. **관찰의 한계를 지킨다.** A에서 기포가 관찰되지 않았다는 사실은 관찰 시간과 조건에서 뚜렷한 기포가 없었다는 뜻입니다. 효소가 없으면 분해가 물리적으로 절대 일어날 수 없다는 뜻은 아니에요. 또한 C의 관찰은 이 실험에 제시된 용액의 성질을 나타냅니다.

### 보기와 선지의 판정

| 대상 | 판정과 이유 |
|---|---|
| ㄱ | 옳음. 효소는 활성화 에너지를 낮추어 분해 반응을 촉진한다. |
| ㄴ | 옳음. 생성된 산소 분자의 원자들은 공유 결합한다. |
| ㄷ | 옳음. C·D에서 BTB를 공통으로 두고 시험 용액을 달리하여 산성을 확인한다. |
| ① ㄱ | 옳은 ㄴ·ㄷ을 빠뜨렸다. |
| ② ㄷ | 옳은 ㄱ·ㄴ을 빠뜨렸다. |
| ③ ㄱ, ㄴ | 옳은 ㄷ을 빠뜨렸다. |
| ④ ㄴ, ㄷ | 옳은 ㄱ을 빠뜨렸다. |
| ⑤ ㄱ, ㄴ, ㄷ | 정답이다. |

### 실수 점검과 복습

가설2를 A와 B로 검증하려 했다면 측정 지표가 무엇인지 놓친 것입니다. 효소가 활성화 에너지를 높여 더 강하게 반응시킨다고 생각했다면 반응 시작에 필요한 장벽의 뜻을 복습하세요. 돌아갈 곳은 **03 시스템과 상호작용의 효소**, **02 물질과 규칙성의 공유 결합**, **04 변화와 다양성의 지시약**입니다.

### 다른 문제에 옮길 전략

가설마다 **바꿀 조건·같게 둘 조건·관찰할 값**을 따로 적습니다. 대조쌍은 결과가 크게 다른 쌍이 아니라 **검증하려는 조건만 비교할 수 있는 쌍**입니다. 원자료의 물음표는 필요한 증거가 없으면 그대로 남깁니다.

## 10 내성의 발생과 선택을 시간 순서로 나누기 [KICE-2024-Q10]

**공식 정답: ④ — ㄴ, ㄷ.** 원문 PDF70쪽, 공식 문항 정보·정답 PDF71쪽. 검은 내성 세균과 흰 감수성 세균의 범례, X처리 전후, 처리 중단 후의 조건을 확인했다. (가)는 내성2·감수성10, (나)는 내성2·감수성1로 세어 확인했다. (다)의 구체적인 총개체 수는 원문에 제시되지 않았다.

### 왜 묻는가

**공식 평가 초점:** 항생제 내성 자료에서 변이와 자연선택을 구분하고 집단 내 비율 변화를 해석한다. 행동 영역은 ‘자료 변환 및 해석’이다.

이 문제의 핵심은 세균 한 마리가 필요에 따라 몸을 바꾸었다는 이야기가 아니에요. **처리 전에도 서로 다른 형질의 세균이 있었고, 환경에서 살아남는 비율이 달라졌다**는 이야기입니다.

### 처음 확인할 조건

- 내성은 돌연변이에 의해 생기며 다음 세대로 유전된다고 제시했다.
- X가 없는 조건에서는 내성 세균과 감수성 세균의 증식 속도가 같다.
- (가)→(나)는 X처리, (나)→(다)는 X를 처리하지 않는 단계이다.
- 묻는 것은 내성 세균의 절대 수만이 아니라 집단에서 차지하는 **비율**이다.

### 순서대로 풀기

1. **내성이 언제 생길 수 있는지 판단한다.** 내성 돌연변이는 항생제가 없는 상태에서도 발생할 수 있습니다. (가)의 그림에도 이미 내성 세균이 있어요. 항생제는 필요한 내성을 목적에 맞게 만들어 주는 명령이 아닙니다.
2. **처리 전후 생존 차이를 읽는다.** (가)의 내성 비율은2/(2+10)=1/6이고, (나)는2/(2+1)=2/3입니다. 내성 세균의 그림 속 수가2로 같아도 감수성 세균이 크게 줄어 내성의 비율이 높아졌습니다. 기존 변이에 작용한 자연선택으로 설명합니다.
3. **처리 중단 뒤의 조건을 적용한다.** X가 없을 때 두 종류의 증식 속도가 같다면 (나)의2:1 관계가 같은 배수로 증가합니다. 둘 다 k배가 되어도2k:k=2:1이지요. 따라서 (다)의 내성 비율은 (나)와 같은 높은 비율로 유지되는 모형이며, (가)보다 높습니다.
4. **총수와 비율을 따로 둔다.** (다)에 세균이 정확히 몇 마리인지, 시간이 얼마나 지났는지는 주어지지 않았습니다. 비율을 판단하는 데 필요한 정보와 절대 개체 수에 필요한 정보는 다릅니다.

### 보기와 선지의 판정

| 대상 | 판정과 이유 |
|---|---|
| ㄱ | 틀림. X에 노출되기 전에도 내성 돌연변이가 생길 수 있다. |
| ㄴ | 옳음. 처리 전부터 있던 형질 차이가 생존 차이로 이어져 자연선택이 작용한다. |
| ㄷ | 옳음. 처리 뒤 높아진 내성 비율이 같은 증식 속도 조건에서 유지되므로 (다)가 (가)보다 높다. |
| ① ㄱ | 틀린 보기만 골랐다. |
| ② ㄷ | 옳은 ㄴ을 빠뜨렸다. |
| ③ ㄱ, ㄴ | 틀린 ㄱ을 포함하고 ㄷ을 빠뜨렸다. |
| ④ ㄴ, ㄷ | 정답이다. |
| ⑤ ㄱ, ㄴ, ㄷ | 틀린 ㄱ을 포함했다. |

### 실수 점검과 복습

‘내성 세균 수가2로 같으니 선택이 없다’고 생각했다면 분모를 확인하세요. ‘항생제를 끊으면 자동으로 처음 비율로 돌아간다’고 생각했다면 같은 증식 속도 조건을 사용하지 않은 것입니다. 돌아갈 곳은 **04 변화와 다양성의 변이·자연선택**, **01 과학의 기초의 부분/전체 비율**입니다.

### 다른 문제에 옮길 전략

**변이의 발생 → 선택 환경 → 생존·번식 차이 → 집단 비율 변화**를 분리합니다. 항생제를 제거한 뒤에도 높은 비율이 유지된다는 결론은 이 문제의 같은 증식 속도 조건에서 도출한 것입니다. 다른 상황에서 두 종류의 증식·사망·이동 조건이 달라지면 비율도 달라질 수 있습니다. 이 모형을 실제 약 복용 방법의 지침으로 바꾸지 않습니다.

## 11 단위체와 유전정보의 조합 수 연결하기 [KICE-2024-Q11]

**공식 정답: ③ — ㄱ, ㄴ.** 원문 PDF72쪽, 공식 문항 정보·정답 PDF73쪽. ⓐ·ⓑ의 설명, DNA→RNA→단백질 그림, 두 염기16가지·세 염기64가지라는 조건을 확인했다.

### 왜 묻는가

**공식 평가 초점:** 단백질과 핵산이 기본 단위체의 결합으로 구성됨을 알고, 유전정보에서 단백질이 만들어지는 관계에 적용한다. 행동 영역은 ‘적용’이다.

그림에 DNA라는 이름이 크게 보인다고 ⓐ를 DNA로 찍으면 안 돼요. 먼저 문장에 나온 **어떤 단위로 만들어지는가**를 이용해 정체를 정해야 합니다.

### 처음 확인할 조건

- ⓐ의 합성에 이용되는 단위는 약20종의 아미노산이다.
- ⓑ는 그 아미노산의 종류와 배열에 관한 정보를 가진다.
- 염기 두 개의 조합 수16과 세 개의 조합 수64는 가능한 정보 조합의 수이며 실제 아미노산 종류의 수와 같은 말이 아니다.

### 순서대로 풀기

1. **ⓐ와 ⓑ를 정한다.** 아미노산으로 이루어지는 ⓐ는 단백질입니다. 단백질 구성에 관한 유전정보를 가진 ⓑ는 DNA입니다. 그림의 화살표는 정보 흐름을 나타내며 DNA 전체가 사라져 단백질 물질로 바뀐다는 뜻이 아닙니다.
2. **단백질의 기능을 연결한다.** 단백질은 효소의 구성 성분으로 기능합니다. 따라서 ㄱ은 옳습니다. 이 보기를 ‘어떤 촉매 기능도 단백질만 할 수 있다’는 더 넓은 명제로 확장할 필요는 없습니다.
3. **DNA의 단위체를 정확히 말한다.** DNA의 단위체는 뉴클레오타이드입니다. 인산·당·염기로 구성되며, 염기 A·T·G·C에 따라 네 종류를 구분합니다. DNA가 ‘염기만 이어 붙인 물질’이라는 뜻은 아니에요.
4. **두 염기로 충분한지 계산한다.** 한 자리에 네 선택이 있으므로 두 자리 조합은4×4=16가지입니다. 이 방식으로 약20종의 아미노산을 모두 구별해 지정하기에는 부족합니다. 세 자리는4×4×4=64가지로 필요한 조합 수를 확보할 수 있어요. 따라서 두 염기가 한 아미노산을 지정한다는 ㄷ은 옳지 않습니다.

실제 유전정보는 세 염기 단위로 읽힙니다. 64가지 조합이 있다고 실제 아미노산이64종이라는 뜻은 아니며, 여러 조합이 같은 아미노산을 지정하거나 종결 신호가 되는 경우가 있습니다.

### 보기와 선지의 판정

| 대상 | 판정과 이유 |
|---|---|
| ㄱ | 옳음. ⓐ는 단백질이며 효소의 구성 성분이다. |
| ㄴ | 옳음. ⓑ는 DNA로, 염기에 따라 네 종류의 뉴클레오타이드를 갖는다. |
| ㄷ | 틀림. 두 염기의 조합16가지로는 약20종을 모두 지정할 수 없다. |
| ① ㄱ | 옳은 ㄴ을 빠뜨렸다. |
| ② ㄴ | 옳은 ㄱ을 빠뜨렸다. |
| ③ ㄱ, ㄴ | 정답이다. |
| ④ ㄱ, ㄷ | 틀린 ㄷ을 포함하고 ㄴ을 빠뜨렸다. |
| ⑤ ㄴ, ㄷ | 틀린 ㄷ을 포함하고 ㄱ을 빠뜨렸다. |

### 실수 점검과 복습

뉴클레오타이드와 아미노산을 뒤바꾸었다면 단위체 비교표로 돌아가세요. 4+4=8로 계산했다면 두 자리에 들어갈 선택을 각각 조합한다는 뜻을 그림으로 확인하면 됩니다. 돌아갈 곳은 **02 물질과 규칙성의 ‘지각과 생명체를 이루는 기본 단위’**, **03 시스템과 상호작용의 유전정보 흐름**입니다.

### 다른 문제에 옮길 전략

**구성 단위 → 물질의 정체 → 기능 → 정보 조합**의 순서를 사용합니다. ‘최대 가능한 조합 수’와 ‘실제로 지정하는 서로 다른 대상 수’를 같게 놓지 않습니다. 코돈표가 제시된 문제에서는 실제 대응표를 따라야 하며, 한 염기 변화가 반드시 다른 아미노산을 뜻한다고 일반화하지 않습니다.

## 12 표의 숫자로 그래프 이름을 찾아내기 [KICE-2024-Q12]

**공식 정답: ③ — ㄱ, ㄷ.** 원문 PDF74쪽, 공식 문항 정보·정답 PDF75쪽. 센서 종류·30초 기록 간격, 표의 연번1·110~114·200, 그래프A~D의 세로축 범위와 변화 모양, 결론을 확인했다. 그래프에서 모든 순간의 정확한 값을 읽었다고 가정하지 않고, 표의 명시값과 곡선의 범위를 대조했다.

### 왜 묻는가

**공식 평가 초점:** 디지털 센서의 기상 자료를 표에서 그래프로 변환하고 경향성을 해석한다. 행동 영역은 ‘자료 변환 및 해석’이다.

그래프 모양이 비슷한 C와 D를 구별하는 데 기상 지식만 필요한 것은 아니에요. 표에서 특정 연번의 숫자를 골라 그래프 세로축과 맞추면 정확하게 찾을 수 있습니다.

### 처음 확인할 조건

- 표의 열은 기온(℃), 기압(hPa), 절대 습도(g/m³), 이슬점(℃)이다.
- 가로축은 **연번**이다. 연번 자체를 분이나 시각이라고 읽지 않는다. 연속 기록 사이 간격은30초라고 별도로 제시했다.
- A~D의 세로축 범위가 서로 다르다.
- 결론은 ‘대체로’라는 자료의 경향을 말한다. 모든 점에서 완전히 같은 비율이라는 뜻이 아니다.

### 순서대로 풀기

1. **자료 표현의 변화를 확인한다.** 자료1은 표이고 자료2는 그 수치들을 시간 순서의 그래프로 나타낸 것입니다. 따라서 ㉠에는 그래프로 변환한다는 설명이 들어갑니다. 실제 측정값을 임의로 바꾸는 것과 표현 형식을 바꾸는 것은 달라요.
2. **범위가 뚜렷한 두 열부터 연결한다.** A는 약27~28℃ 부근으로 기온과 맞습니다. B는 약997hPa 부근으로 기압과 맞아요. 기압의 숫자를 온도처럼 읽지 않습니다.
3. **C와 D를 표의 기준점으로 구별한다.** 연번1에서 절대 습도는11.2, 이슬점은12.8입니다. C는11대에서 시작하고 D는13 근처에서 시작합니다. 또 연번112에서 절대 습도13.1, 이슬점15.1이므로 C의 봉우리와 D의 봉우리에 각각 대응합니다. 따라서 C가 절대 습도, D가 이슬점입니다.
4. **함께 변하는 방향을 확인한다.** C가 높아지는 구간에서 D도 대체로 높아지고, C가 낮아지는 구간에서 D도 대체로 낮아집니다. 자료에서는 공기 중 수증기량이 많을수록 이슬점이 대체로 상승한다는 경향을 읽을 수 있습니다.

**용어 점검:** 절대 습도는 공기 단위 부피당 수증기의 질량이다. 이슬점은 주어진 공기를 수증기량 변화 없이 식힐 때 응결이 시작되는 온도로 이해할 수 있다. 절대 습도는 g/m³, 이슬점은℃이며, 상대 습도의%와도 구별한다.
